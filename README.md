# 贷款组合管理器

纯静态多笔贷款合并计算与提前还款分析工具。

## 核心功能

- **多笔合并计算**：支持商业贷款、公积金贷款、车贷与消费贷等最多 20 笔贷款合并测算与时间线对齐。
- **房贷组合模板**：提供公积金与商业房贷一键配对模板。
- **提前还款分析**：支持缩短期限与减少月供两种策略，实时测算省息效益与缩短月数。
- **大写金额换算**：输入金额实时转换为规范中文大写与万元单位。
- **数据导出**：支持单笔明细与合并总表 CSV 导出。

## 快速启动

本项目为纯静态单页面应用，无第三方依赖与编译步骤，直接启动静态服务器即可：

```bash
python3 -m http.server 8000
```

启动后在浏览器打开 `http://localhost:8000/`。

## 自动化测试

运行静态检查与 18 项贷款计算测试套件：

```bash
npm run check
```
