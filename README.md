# 💾 我的电脑 - 贷款组合管理器.exe (Combined Loan Calculator 98)

> **极具情怀的 Windows 98 经典复古桌面版 —— 通用多笔贷款组合大沙盘**

这是一个将**现代多笔债务聚合合并算法**与 **Windows 98 经典操作系统视觉**完美融合的纯静态 Web 网页应用。它解决了传统贷款计算器“无法实时计算”和“无法合并多笔债务”的痛点，支持添加无限笔贷款，并根据它们的首次还款年月及期限，完美投射到同一条自然月时间线上，帮助您全局看清未来的负债状况。

项目完全适配 **GitHub Pages** 静态托管，无需任何后端服务器和数据库，即开即用。

---

## ✨ 项目特色与功能升级

1. **⚡ “零延迟”反应式实时重算 (Reactive Calculation)**
   * 彻底摒弃了传统网页上的“开始计算”按钮。
   - 监听所有输入域的变更事件，一旦输入了最小可计算数据，后台将在毫秒级内自动重算所有本息明细并同步刷新图表。

2. **📊 多笔贷款合并与时间线对齐 (Multi-loan Aggregation)**
   - **动态配置文件**：通过左侧“资源管理器”树形导航，使用“➕ 新增贷款.lnk”可以无限添加独立的贷款配置文件。
   - **自定义命名**：支持为每笔贷款自定义命名，例如 `贷款 1`、`贷款 2` 或任何您指定的名称，保持完美的通用性。
   - **🔥 杀手级功能——“未来月供变化趋势图”**：将开始时间、还款年限各异的多笔贷款全部投影到同一条**自然月时间线**上，合并累加每个月需要偿还的总额，清晰指出“哪个月还款压力最高”、“何时能彻底卸下某一笔债务”。

3. **🖥️ 100% 像素级还原的 Windows 98 经典视觉**
   - 经典灰（`#d4d0c8`）面板与标志性的青绿色桌面（`#008080`）。
   - 双层立体 3D 雕刻感边框，像素 Tahoma 与宋体点阵字形，经典的 Windows 98 滚动条。
   - 像素按钮在点击时文字会自动向右下方**偏移 1 像素**，呈现极佳的拟交互回弹感。
   - 底部常驻任务栏、动态走字的小时钟 🕒 以及可以弹出的经典“开始菜单”。

4. **📈 “系统性能监视器”复古堆叠图表**
   - 引入 Chart.js 绘制堆叠柱状图，但经过了深度“复古化皮肤”定制：使用虚线点状像素网格线、Tahoma 字体、直角悬浮框，完美模拟 90 年代的系统检测曲线。

## 🛠️ 文件组织结构

项目极其精炼，完全由三个高内聚的静态文件组成：
* `index.html` - Windows 98 桌面骨架与主视窗 DOM。
* `styles.css` - 3D 边框、滚动条、树形控件及任务栏的 Windows 98 经典样式系统。
* `app.js` - 等额本金/等额本息还款公式、多笔时间线合并算法、树形同步与 Chart.js 渲染。

## 🚀 运行与部署指南

### 1. 本地启动运行
由于本应用是**纯静态单页面应用**，无需安装任何依赖（如 Node.js 或 npm）。
* 您只需双击项目根目录下的 [index.html](file:///Users/luku/Combined-Loan-Calculator/index.html) 文件，即可直接在电脑浏览器中离线打开并使用！
* 所有的贷款数据都会实时、安全地保存在您浏览器的本地存储（LocalStorage）中，刷新或关闭网页后数据不会丢失。

### 2. 部署到 GitHub Pages (点击 github.io 在线使用)
如果您想将应用发布到 Github 上，在线点击使用，请遵循以下简单步骤：

1. **在 GitHub 上新建仓库**：
   - 登录您的 GitHub 账号，创建一个名为 `Combined-Loan-Calculator` 的公开（Public）新仓库。
2. **将本地代码推送到该仓库**：
   ```bash
   git remote add origin https://github.com/您的用户名/Combined-Loan-Calculator.git
   git branch -M main
   git push -u origin main
   ```
3. **开启 GitHub Pages**：
   - 进入您在 GitHub 的该仓库页面，点击右上角的 **Settings** (设置)。
   - 在左侧菜单栏中选择 **Pages**。
   - 在 **Build and deployment** 下的 **Branch** 处，选择 `main` 分支和 `/ (root)` 目录，然后点击 **Save** (保存)。
4. **在线访问**：
   - 等待约 1-2 分钟，GitHub 会为您自动生成一个部署链接：
     `https://您的用户名.github.io/Combined-Loan-Calculator/`
   - 您只需点击该链接，便可在电脑、iPad 或手机浏览器中随时随地使用了！

## ⚖️ 核心还款计算公式说明

* **等额本息 (ACPI)**：每月还款额固定。
  $$A = P \times \frac{R \times (1 + R)^N}{(1 + R)^N - 1}$$
* **等额本金 (ACP)**：每月还款本金固定，利息逐月递减。
  $$P_m = \frac{P}{N}, \quad I_m = (P - (m - 1) \times P_m) \times R$$

*(其中：$P$ 为贷款本金，$R$ 为月利率，$N$ 为还款总月数，$m$ 为当前期数)*
