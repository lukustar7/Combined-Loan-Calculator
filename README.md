# 贷款组合管理器 (LoanLens)

贷款组合管理器是一款纯静态的多笔贷款合并计算与提前还款分析工具。数据全程仅在本地浏览器运算与存储，无任何网络上传，全面保障个人财务隐私。

## 功能介绍

### 多笔贷款合并测算
- 支持商业贷款、公积金贷款、汽车贷款、消费贷款等最多 20 笔贷款同时合并计算。
- 支持错峰起贷，自动按自然月对齐跨度长达数十年、起止时间各异的多笔贷款时间线。
- 自动计算每月合并总月供、累计总利息、本息总额，并精准定位月供峰值月份与常规月供负荷。

### 房贷组合一键模板
- 提供公积金贷款与商业房贷一键配对模板，自动对齐起贷年月与期限，快速生成组合贷款方案。

### 主流还款方式支持
- 等额本息：每月还款额固定，本金递增、利息递减，便于资金规划。
- 等额本金：每月归还本金固定，月供逐月递减，总利息支出更少。
- 支持同一组合内不同贷款各自采用不同的还款方式。

### 提前还款与省息效益分析
- 支持在任意还款月份录入单次或多次提前还款。
- 提供缩短还款期限与减少月供金额两种策略。
- 实时测算并直观展示提前还款方案累计节省的利息总额与缩短的还款月数。

### 可视化走势图表
- 单笔走势对比模式：清晰展示等额本息水平线、等额本金递减线以及合并总月供负荷曲线。
- 组合堆叠构成模式：直观呈现每月月供中各笔贷款的资金占比与消长过程。
- 内置 20 色高辨识度调色板，多笔贷款区分明确。

### 金额大写与万元换算辅助
- 输入金额时，实时显示规范的人民币财务大写金额与万元换算提示，避免大额数字输错位数。

### 双视觉主题切换
- Windows 98 经典复古风格：还原经典桌面图标、开始菜单、任务栏与对话框交互。
- Google Material 3 现代质感风格：现代卡片式布局与动效。
- 支持在界面上一键无缝切换风格。

### 移动端与全端触控适配
- 移动端横向滑动手势胶囊栏，便于快速切换不同贷款。
- 金额与期数输入自动唤起移动端原生数字键盘。
- 针对窄屏手机与平板深度排版适配，杜绝屏幕跳动与内容遮挡。

### 离线使用与桌面安装 (PWA)
- 内置离线缓存支持，断网或无网络环境下依然可以顺畅使用全部计算功能。
- 支持添加到手机主屏幕或电脑桌面，作为独立应用即点即用。

### 数据安全与表格导出
- 本地自动保存：输入内容即时安全保存至本地浏览器，页面关闭或切后台数据不丢失。
- 表格导出：支持一键导出单笔贷款明细表与全周期合并还款计划表为 CSV 文件，完美兼容各类表格软件打开。

## 使用方式

本项目为纯静态单页面应用，无需编译，无后端服务依赖。

可以通过任意静态文件服务器运行，例如使用 Python 启动本地服务：

```bash
python3 -m http.server 8000
```

启动后在浏览器中访问 `http://localhost:8000/` 即可使用。
